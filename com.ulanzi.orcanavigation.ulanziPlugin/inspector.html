Apple Silicon Mac은 화면 조회 없이 Orca에 키를 직접 전달합니다. Orca 창 하나를 열어 두세요. 탭(모든 유형) 이동은 열린 모든 탭 사이를 이동합니다. Orca 열기은 앱을 열거나 앞으로 가져옵니다.

설정 도움말

Windows·Intel Mac은 기존 CLI 경로를 사용하며 실기 미검증입니다. Windows는 CLI index.js 절대 경로 또는 네이티브 .exe를 지정하세요. .cmd와 셸 명령은 실행하지 않습니다. Apple Silicon Mac에서는 CLI 경로를 사용하지 않습니다.

워크트리 목록은 Mac에서 ⌘⇧0, Windows에서 Ctrl+Shift+0 후 ↑/↓, 탭(모든 유형)은 Mac에서 ⌘⇧[/], Windows에서 Ctrl+Shift+[/]를 전달합니다. 회전은 왼쪽=이전, 오른쪽=다음입니다. 누름·누른 채 회전은 사용하지 않습니다. 처리 중 추가 입력은 버립니다.

확인은 Enter, 취소는 Esc를 현재 포커스에 보냅니다. 입력창에서는 전송, 메뉴에서는 선택·닫기로 동작할 수 있습니다. 받아쓰기는 기존 음성 설정을 사용합니다. 새 에이전트 탭은 macOS 전용입니다.
