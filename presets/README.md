# Orca D200X 프리셋 — 0.0.1

**가져오기 확인:** Studio 3.4.8에서 버튼 11개·노브 3개가 재가져오기·재시작 후 보존됐다. 가져온 프리셋의 전체 물리 입력 재시험은 미확인이다.

macOS 기준으로 배치한 버튼 11개·노브 3개·시계·기본 페이지 이동을 저장했다. Studio 자체 내보내기 파일을 기준으로 상대 이미지 경로와 문자열 `Version: "2.0"`을 유지하고, 기기 ID는 공용 영(0) UUID, 플러그인 버전은 0.0.1로 정리했다. 내보내기에는 Orca 앱 연결 정보가 포함되지 않아 가져온 뒤 앱 연결은 직접 지정해야 한다.

| 위치 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 위 | 취소 (Esc) | 비움 | Orca 열기 | 좌측 사이드바 | 우측 사이드바 |
| 가운데 | 이전 워크트리 | 이전 탭 | 새 에이전트 탭 | 다음 탭 | 확인 (Enter) |
| 아래 | 다음 워크트리 | 비움 | 받아쓰기 | 시계 | 시계 |
| 노브 | 해당 없음 | 해당 없음 | 워크트리 탐색 | 전체 탭 탐색 | 마우스 휠 |

휠은 왼쪽=위, 오른쪽=아래이며 마우스 포인터가 놓인 영역을 스크롤한다.

## 검증용 가져오기

플러그인을 먼저 설치한 상태에서 **기본 설정 → 프리셋 → 가져오기**로 `Orca-D200X-macOS-0.0.1.ulanziDeckProfile`을 선택한다. 프리셋 자체는 플러그인을 설치하지 않는다. 기존 정상 프리셋을 교체하지 않고 별도 등록해 비교한다.

플러그인 설치·업데이트 후에는 Ulanzi Studio를 완전히 종료하고 다시 실행한다. 실행 중 파일만 교체한 뒤 버튼에 경고가 나타나면 먼저 Studio를 재시작한다.

Studio 3.4.8에서 재가져오기·재시작 후 버튼 11개·노브 3개가 보존되는 것을 확인했습니다. Windows 실기와 가져온 프리셋의 전체 물리 입력은 미검증입니다. 헤더 등 파일 형식은 [개발 안내](../docs/development.md)를 참고하세요.

## 재생성

```sh
python3 tools/build-plugin.py
python3 tools/build-preset.py
```

묶음에는 플러그인 ZIP, 별도 가져오기용 프리셋, 이 안내(INSTALL.md), MIT LICENSE가 들어간다. 마켓의 플러그인 업로드에는 내부 플러그인 ZIP을 사용한다.
